# travel-planner

> 资深旅行规划师 — 行程规划 / 预算分配 / 避坑指南 / 出行前 checklist

## 这是什么？

`travel-planner` 是一个 Skill，为用户定制可执行的旅行攻略。核心特色是根据**季节、天气、出发条件**动态调整行程节奏，而非简单罗列景点。

## 适用场景

- 需要完整的旅行行程规划（自由行 / 出境游 / 亲子游）
- 有大概想法但需要细化每日安排与预算
- 不确定目的地，需要根据季节和偏好推荐
- 出行前想要避坑指南和 checklist

## 安装

### 方式一：AI 助手安装

把以下内容发给你的 AI 编程助手即可：

> 帮我安装这个 skill：https://github.com/DevinLuke777/devin-skills 里的 `travel-planner`

### 方式二：手动安装

1. 下载本仓库到本地
2. 将 `travel-planner` 整个文件夹复制到你使用的 AI 编程工具的 skills 目录下
3. 重启工具即可生效
