# Mercado Ads 实操 Playbook（双站）

> 通用打法双站适用；关键词必须用站点本地化语言（葡语=巴西 / 西语=墨西哥），用词差异按两站 Listing 指南的「本地用词对照」执行。

## 一、广告体系认识（Mercado Ads / Product Ads）

- 本质是**按点击付费（CPC）的搜索/详情页广告**，出现在搜索结果 + 竞品/相关详情页。
- 关键词必须**站点本地化**：巴西 vivo（葡语）、墨西哥 en vivo（西语）——即「活动/直播」类词不适用，按 product search terms 投放。
- 指标：Impresiones（曝光）、CTR、CVR、Ticket médio（客单价）、CPC、ACOS（广告销售额成本率）。

## 二、新品冷启动打法

1. **低价引流款 + 高相关长尾词**：新品无销量信誉，先用低价款 + 精准长尾词小预算拉曝光与首单。
2. **手动低出价试探**：手动广告先给试探性出价，观察 CTR 与点击。
3. **补全属性 + 首图/视频**：广告引流后页面质量决定 CVR，属性不全、首图差则广告白烧。
4. **累积销量与 Reputação/MercadoLíder**：广告帮助冲销量 → 信誉/领跑者徽章 → 自然曝光加权，形成正循环。
5. **先盯词再放量**：冷启动期聚焦「有转化的小词」，不盲目投大词。

## 三、大促前广告节奏（双站通用）

- 大促前 **2–3 周**开始提预算、测款、扩充关键词并抢坑位（大促当日流量集中、竞争激烈、价格下行）。
- 大促期间广告目标从「拉新曝光」转向「收割转化」，配合 Buy Box / Full 时效保住转化。
- 大促后复盘：哪些词贡献 ACOS 健康、哪些词烧钱无转化，据此优化结构与预算分配。

## 四、日常 ACOS 优化路径

1. 设 ACOS 目标（结合毛利率反推，预留广告毛利红线）。
2. 分关键词组（精准/广泛/否定），单独观察。
3. **否定词**管理：屏蔽只烧钱不转化的废词（可参考竞品标题做否定）。
4. A/B 测试素材：标题、首图、视频、广告文案（葡/西）。
5. 每周复盘：Impresiones 是否虚高、CVR 是否受页面影响、Ticket médio 是否达预期。

## 五、后台复盘指标对照

| 指标 | 含义 | 优化动作 |
|------|------|----------|
| Impresiones | 曝光量 | 曝光低 → 扩关键词/提价 |
| CTR | 点击率 | 低 → 优化标题/首图/价格吸引力 |
| CVR | 转化率 | 低 → 页面属性/详情/评分/时效口碑 |
| CPC | 单次点击成本 | 高 → 降出价/否定词/更精准词 |
| ACOS | 广告成本率 | 高 → 控出价、调结构、提转化 |
| Ticket médio | 客单价 | 低 → 组合销售/提客单策略(免息分期/Pix 折扣组合) |

> 具体出价、预算、费率随市场波动，运行中「以卖家当前后台数据为准」。
