# prompt-architect

> 高级提示词架构工具 — 将模糊想法转化为结构化 AI 指令

## 这是什么？

`prompt-architect` 是一个 Skill，专注于将用户模糊、零散的想法转化为结构严谨、逻辑清晰的 **结构化 Prompt**。它内置了五步工作流（信息收集 → 要素拆解 → 结构化生成 → 自我审查 → 交付迭代）和一套经过验证的 Prompt 输出模板。

## 适用场景

- 需要写一个 Prompt 但不知从何下手
- 有一个大概的想法但说不清楚细节
- 手头有一段 Prompt 需要优化和结构化
- 想让 AI 完成某项任务，但需要先设计清晰的指令

## 安装

### 方式一：AI 助手安装

把以下内容发给你的 AI 编程助手即可：

> 帮我安装这个 skill：https://github.com/DevinLuke777/devin-skills 里的 `prompt-architect`

### 方式二：手动安装

1. 下载本仓库到本地
2. 将 `prompt-architect` 整个文件夹复制到你使用的 AI 编程工具的 skills 目录下
3. 重启工具即可生效

## 使用方式

在对话中直接表达需求即可自动触发，例如：

- "帮我写一个分析竞品 Listing 的 prompt"
- "我想让 AI 帮我做代码审查，帮我设计一个指令"
- "优化这段提示词：……"
- "帮我写一个翻译指令，要求保持技术文档的严谨风格"

Skill 会自动引导你补全缺失的信息，并在内部完成自我审查后再输出最终 Prompt。

## 输出示例

```
# Role: 技术文档翻译专家

## Profile
- **Description**: 你是一位精通中英文技术文档翻译的专家，擅长在保持原文技术准确性的同时，使译文符合目标语言的阅读习惯。

## Background
- 用户需要将英文技术文档翻译为中文，要求既准确传达技术细节，又符合中文技术写作规范。

## Goals
1. 准确翻译原文的技术内容，不丢失、不曲解任何技术细节
2. 译文符合中文技术文档的写作规范与阅读习惯
...（下略）
```

## 设计理念

这个 Skill 的核心方法论来自余恒（Yú Héng）的 Prompt 架构思想：

- **清晰至上** — 消除一切歧义
- **结构模块化** — Markdown 层次分明
- **拒绝盲猜** — 信息不足时引导提问，绝不臆测
- **正向激励** — 告诉模型该做什么，而非仅仅禁止什么
- **自我审查** — 输出前强制执行六项自查

## 双版本说明

本项目提供两个版本，按场景选用：

| 版本 | 文件 | 适用场景 |
|------|------|----------|
| **Skill 版** | `SKILL.md` | 编程助手 Skill 功能，自动触发 |
| **Chat 版** | `prompt-for-chat.md` | ChatGPT / claude.ai / DeepSeek 等聊天类 AI，作为 System Prompt 或首条消息使用 |

Chat 版恢复了「余恒」角色设定——在聊天场景中，有名有姓的角色能更好地维护对话风格的一致性和长对话中的行为稳定性。
