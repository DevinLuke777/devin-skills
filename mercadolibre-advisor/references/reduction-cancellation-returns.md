# 降低取消 / 退货率专项（双站跨境）

> 巴西/墨西哥跨境卖家的取消率与退货率偏高，直接影响 Reputação/MercadoLíder、Buy Box、活动资格与广告权重。本清单按「取消」与「退货」两类给双站跨境解法。

## 一、降低取消率（不发、延迟、买家取消）

| 原因 | 解法 |
|------|------|
| **物流时效不达标/发货慢** | 优先用 Mercado Envíos Full / Flex 达标时效；预留清关缓冲；避免承诺 < 实际时效 |
| **缺货/库存不足** | 每周对账、大促前备货；低动量品用 Flex/Standard 而非 Full 占仓；补货断档及时下架 |
| **买家因等待取消** | 页面如实展示预计送达；物流信息及时同步；客服催发货沟通 |
| **虚假发货/单号无效** | 严禁填假单号（红线——会被判信誉违规）；只填真实追踪号 |
| **支付失败** | 巴西 Pix 秒到账最稳；墨西哥支持 OXXO/分期时引导到支付成功率高的方式 |

## 二、降低退货率

| 原因 | 解法 |
|------|------|
| **与描述不符** | 图片/属性如实（尺寸、颜色公差、材质）；标题与详情一致；规格参数清晰 |
| **质量问题/次品** | 头程前质检抽检；包装加固（易碎用缓冲）；大件/易损品慎用低价直发 |
| **尺寸/适配误解** | 变体字段给足（Tamanho/Talla）；页面放测量图与适配说明 |
| **跨境运费/关税误解** | 页面明示平台代收关税（Remessa Conforme）；不知情关税是退货高发诱因 |
| **冲动购买后悔** | 页面给足真实信息降低预期差；避免过度夸大（合规） |

## 三、PS：双站专属提示

- **巴西**：Pix 支付退货/取消更顺（即时到账、即时退款）；Remessa Conforme 的关税预收避免"货到要补税"的退货源。
- **墨西哥**：OXXO 现金购物的部分人群退款路径更长 → 页面写清退款规则；免息分期退单的金额抵扣要处理干净，避免纠纷。

## 四、执行计划（行动清单）

1. 上线前：类目/规格/图片质检 + 时效如实承诺 + 认证门槛过 `product-selection-filter`。
2. 运营中：周维度盯「取消率 + 延迟率 + 纠纷率」指标，异常即定位（发货/缺货/描述/物流）。
3. 大促前：备货 + 履约模式切换（爆款 Full）+ 广告预算，避免大促崩时效导致取消率飙升。
4. 发生纠纷：及时响应、留证、按平台流程处理，控制 Reputação 损失。
