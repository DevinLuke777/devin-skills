# family-kitchen-tutor

> 家庭厨房全科导师 — 教做菜 + 推荐菜谱，从一道菜讲到底层原理，授人以渔

## 这是什么？

`family-kitchen-tutor` 是一个 Skill，专注于把专业烹饪知识拆解成家庭厨房可落地的操作方案。每次教做菜，不仅告诉用户"怎么做"，还讲清楚"为什么这样做"——建立可迁移的烹饪认知，让用户能举一反三。

核心方法：原理溯因 + 错误容灾 + 能力迁移 + 平实温和的语气。

## 适用场景

### 场景 A — 教做菜

- "红烧肉怎么做"
- "教我做番茄炒蛋"
- "麻婆豆腐怎么做好吃"
- 用户问任意一道具体菜的做法

### 场景 B — 给灵感

- "今天有土豆，能做什么菜"
- "推荐几道家常菜"
- "招待朋友做什么拿手菜"
- 用户给食材或场景求推荐

## 使用方式

在对话中直接说菜名或食材即可自动触发，例如：

- "红烧肉怎么做"
- "可乐鸡翅的家常做法"
- "家里有西红柿和鸡蛋，除了炒还能做什么"
- "推荐 3 道适合 3 个人吃的快手菜"
- "麻婆豆腐总是翻车，豆腐碎成一锅渣怎么办"

## 输出模板

每道菜按以下结构输出（家常菜可简化"灵活变体"和"认知建立"）：

- **🍳 菜品档案** — 名称、风味流派、难度、用时
- **🔬 成功心法** — 1-2 句话讲底层原理
- **⏱ 备菜节奏** — 利用时间差并行操作的备菜顺序
- **🛒 食材准备** — 用量、替代方案、备注
- **🥘 详细步骤** — 操作 + 原理 + 判断标准 + 翻车预警与补救
- **✅ 成品验收标准** — 色泽、质地、气味、口感
- **❓ 常见问题** — 4-5 个高频失败场景 + 原因 + 解决办法
- **🔧 灵活变体**（可选）— 工具/口味变体、举一反三
- **🧠 认知建立**（可选）— 1-2 个可迁移核心技法

## 默认设置（无需询问，自动套用）

- **份量**：2-3 人份
- **厨具**：家庭常用炒锅 / 深锅
- **辣度**：完全不辣（仅用白胡椒粉）
- **场景**：家庭日常烹饪

用户主动提供不同信息（如"做 6 人份"、"我用空气炸锅"、"想做辣的"）时实时适配，不另做询问。

## 设计理念

- **精准复刻** — 步骤清晰可执行，按指引能做出成品
- **原理溯因** — 关键环节解释"为什么"，建立底层认知
- **错误容灾** — 预判翻车场景，提前给避免方法与补救
- **能力迁移** — 结尾总结核心技法应用范围，触类旁通
- **平实温和** — 像朋友教你做菜，不冷冰冰也不过度口语化
