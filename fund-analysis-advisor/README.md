# fund-analysis-advisor

> 基金投资分析与市场情报顾问 — 行情解读 / 基金诊断 / 实盘分析 / 产业链投资机会映射

## 这是什么？

`fund-analysis-advisor` 是一个 Skill，帮助个人投资者解读市场行情、分析基金持仓、诊断实盘组合、识别产业链投资机会。支持从生活观察（如"摄像头涨价"）到投资方向的完整映射。

## 适用场景

- 每日 A股/港股/美股行情速览与异动解读
- 单只基金或基金组合的持仓分析、业绩归因、同类对比
- 分享实盘持仓后，获取系统性的组合诊断与调仓建议
- 板块轮动与风格切换判断
- 事件驱动的产业链拆解——"最近XX涨价了，买什么基金？"
- 定投策略评估与估值分位参考
